  135: =head1 DESCRIPTION
  136: 
  137: C<HTML::OSM> builds an interactive map from OpenStreetMap tiles and the
  138: Leaflet.js library.  Give it points as latitude and longitude, as place
  139: names, or as geocoder result objects.  It can also draw GeoJSON shapes,
  140: heatmaps, GPX tracks and choropleth (colour-filled region) layers, and can
  141: group nearby markers into clusters.
  142: 
  143: Place names are turned into coordinates by an injected geocoder or, without
  144: one, by the Nominatim service.  The answers are cached, and requests can be
  145: spaced out with C<min_interval>.
  146: 
  147: C<onload_render()> returns two HTML fragments: one for the page's
  148: C<< <head> >> and one for its C<< <body> >>.  The interface follows
  149: L<HTML::GoogleMaps::V3>, so code written for that module needs few changes.

 1566: =head1 LIMITATIONS
 1567: 
 1568: =over 4
 1569: 
 1570: =item * B<Per-marker removal>: Markers added via C<add_marker()> cannot yet be
 1571: removed individually by clicking them.  The "Clear search markers" button only
 1572: removes markers added by the in-page Nominatim search box.
 1573: 
 1574: =item * B<Clone validation>: The clone path (C<< $obj->new(%overrides) >>)
 1575: bypasses the Params::Validate::Strict schema so subclasses and internal callers
 1576: can merge arbitrary state.  Callers are responsible for passing valid overrides.
 1577: 
 1578: =item * B<Config-file params unvalidated>: Keys injected by
 1579: L<Object::Configure> from a config file are not re-run through the schema, so
 1580: a malformed config file can introduce invalid types at runtime.
 1581: C<onload_render()> checks C<zoom>, C<max_zoom>, C<width> and C<height> again and
 1582: HTML-escapes the CDN URLs, so a bad value cannot inject markup into the page.
 1583: 
 1584: =item * B<One map per page>: The rendered HTML uses fixed element IDs
 1585: (C<map>, C<search-box>, C<clear-search-button> and C<reset-button>), so two
 1586: maps on the same page will clash.
 1587: 
 1588: =item * B<Clustered circle markers>: With C<< cluster => 1 >>, circle markers
 1589: are grouped with the pin markers, so at low zoom levels a cluster count is
 1590: shown in place of the circles' sizes.  Leave C<cluster> off for a bubble map
 1591: whose sizes should always be visible.
 1592: 
 1593: =item * B<Private-method encapsulation>: C<_fetch_coordinates>, C<_validate>,
 1594: and C<_js_string> are named with a leading underscore by convention only.
 1595: Using L<Sub::Private> in C<enforce> mode would make the contract explicit, but
 1596: that module is not yet listed as a dependency to avoid breaking white-box tests
 1597: in C<t/mock.t>.
 1598: 
 1599: =item * B<Routing>: Turn-by-turn routing (Leaflet Routing Machine / OSRM) is
 1600: explicitly out of scope for this module and will not be added here.
