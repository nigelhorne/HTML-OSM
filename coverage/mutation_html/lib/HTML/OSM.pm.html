  113: =head1 DESCRIPTION
  114: 
  115: C<HTML::OSM> builds an interactive map from OpenStreetMap tiles and the
  116: Leaflet.js library.  Give it points as latitude and longitude, as place
  117: names, or as geocoder result objects.  It can also draw GeoJSON shapes,
  118: heatmaps, GPX tracks and choropleth (colour-filled region) layers, and can
  119: group nearby markers into clusters.
  120: 
  121: Place names are turned into coordinates by an injected geocoder or, without
  122: one, by the Nominatim service.  The answers are cached, and requests can be
  123: spaced out with C<min_interval>.
  124: 
  125: C<onload_render()> returns two HTML fragments: one for the page's
  126: C<< <head> >> and one for its C<< <body> >>.  The interface follows
  127: L<HTML::GoogleMaps::V3>, so code written for that module needs few changes.
