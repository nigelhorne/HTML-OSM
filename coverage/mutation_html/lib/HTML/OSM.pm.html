  169: =head1 DESCRIPTION
  170: 
  171: C<HTML::OSM> builds an interactive map from OpenStreetMap tiles and the
  172: Leaflet.js library.  Give it points as latitude and longitude, as place
  173: names, or as geocoder result objects.  It can also draw GeoJSON shapes,
  174: heatmaps, GPX tracks and choropleth (colour-filled region) layers, and can
  175: group nearby markers into clusters.
  176: 
  177: Place names are turned into coordinates by an injected geocoder or, without
  178: one, by the Nominatim service.  The answers are cached, and requests can be
  179: spaced out with C<min_interval>.
  180: 
  181: C<onload_render()> returns two HTML fragments: one for the page's
  182: C<< <head> >> and one for its C<< <body> >>.  The interface follows

 1933: =head1 LIMITATIONS
 1934: 
 1935: =over 4
 1936: 
 1937: =item * B<Per-marker removal>: Markers added via C<add_marker()> cannot yet be
 1938: removed individually by clicking them.  The "Clear search markers" button only
 1939: removes markers added by the in-page Nominatim search box.
 1940: 
 1941: =item * B<Clone validation>: The clone path (C<< $obj->new(%overrides) >>)
 1942: bypasses the Params::Validate::Strict schema so subclasses and internal callers
 1943: can merge arbitrary state.  Callers are responsible for passing valid overrides.
 1944: 
 1945: =item * B<Config-file params unvalidated>: Keys injected by
 1946: L<Object::Configure> from a config file are not re-run through the schema, so
 1947: a malformed config file can introduce invalid types at runtime.
 1948: C<onload_render()> checks C<zoom>, C<max_zoom>, C<width> and C<height> again and
 1949: HTML-escapes the CDN URLs, so a bad value cannot inject markup into the page.
 1950: 
 1951: =item * B<One map per page>: The rendered HTML uses fixed element IDs
 1952: (C<map>, C<search-box>, C<clear-search-button> and C<reset-button>), so two
 1953: maps on the same page will clash.
 1954: 
 1955: =item * B<Clustered circle markers>: With C<< cluster => 1 >>, circle markers
 1956: are grouped with the pin markers, so at low zoom levels a cluster count is
 1957: shown in place of the circles' sizes.  Leave C<cluster> off for a bubble map
 1958: whose sizes should always be visible.
 1959: 
 1960: =item * B<Private-method encapsulation>: C<_fetch_coordinates>, C<_validate>,
 1961: and C<_js_string> are named with a leading underscore by convention only.
 1962: Using L<Sub::Private> in C<enforce> mode would make the contract explicit, but
 1963: that module is not yet listed as a dependency to avoid breaking white-box tests
 1964: in C<t/mock.t>.
 1965: 
 1966: =item * B<Routing>: Turn-by-turn routing (Leaflet Routing Machine / OSRM) is
 1967: explicitly out of scope for this module and will not be added here.
