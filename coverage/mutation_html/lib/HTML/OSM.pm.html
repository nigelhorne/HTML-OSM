 1908: =head1 LIMITATIONS
 1909: 
 1910: =over 4
 1911: 
 1912: =item * B<Per-marker removal>: Markers added via C<add_marker()> cannot yet be
 1913: removed individually by clicking them.  The "Clear search markers" button only
 1914: removes markers added by the in-page Nominatim search box.
 1915: 
 1916: =item * B<Clone validation>: The clone path (C<< $obj->new(%overrides) >>)
 1917: bypasses the Params::Validate::Strict schema so subclasses and internal callers
 1918: can merge arbitrary state.  Callers are responsible for passing valid overrides.
 1919: 
 1920: =item * B<Config-file params unvalidated>: Keys injected by
 1921: L<Object::Configure> from a config file are not re-run through the schema, so
 1922: a malformed config file can introduce invalid types at runtime.
 1923: C<onload_render()> checks C<zoom>, C<max_zoom>, C<width> and C<height> again and
 1924: HTML-escapes the CDN URLs, so a bad value cannot inject markup into the page.
 1925: 
 1926: =item * B<One map per page>: The rendered HTML uses fixed element IDs
 1927: (C<map>, C<search-box>, C<clear-search-button> and C<reset-button>), so two
 1928: maps on the same page will clash.
 1929: 
 1930: =item * B<Clustered circle markers>: With C<< cluster => 1 >>, circle markers
 1931: are grouped with the pin markers, so at low zoom levels a cluster count is
 1932: shown in place of the circles' sizes.  Leave C<cluster> off for a bubble map
 1933: whose sizes should always be visible.
 1934: 
 1935: =item * B<Private-method encapsulation>: C<_fetch_coordinates>, C<_validate>,
 1936: and C<_js_string> are named with a leading underscore by convention only.
 1937: Using L<Sub::Private> in C<enforce> mode would make the contract explicit, but
 1938: that module is not yet listed as a dependency to avoid breaking white-box tests
 1939: in C<t/mock.t>.
 1940: 
 1941: =item * B<Routing>: Turn-by-turn routing (Leaflet Routing Machine / OSRM) is
 1942: explicitly out of scope for this module and will not be added here.
